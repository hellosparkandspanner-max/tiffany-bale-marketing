# Tiffany Bale Marketing — creative version 3

1. Open `START_HERE_PREVIEW.html` for a self-contained browser preview.
2. When ready to publish, upload `index.html`, `styles.css`, `script.js`, `privacy.html`, and the entire `assets` folder to the root of your GitHub repository.
3. The Formspree endpoint is configured in both the site and standalone preview. Before publishing, complete and review `privacy.html`, confirm contact details, and test a real enquiry from the live GitHub Pages URL. Confirm notifications arrive in your selected email inbox.
4. In GitHub Settings > Pages, use Deploy from a branch, `main`, `/ (root)`.

No client names, logos or unverified metrics are used in the project stories. The project details are edited summaries of the owner's descriptions.
